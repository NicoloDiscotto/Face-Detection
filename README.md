# Face Detection system

## Project Description

The goal was to create an automatic **Face Detection** system, capable of identifying the presence of faces in images and returning the coordinates of the bounding boxes.

## Objective

- Find faces in images
- Return the bounding box coordinates for each detected face
- Return an empty list if the image contains no faces

## Constraints

- No pre-trained models
- Training done **from scratch** with `scikit-learn`.
- Limited computational resources.
- No dataset provided
